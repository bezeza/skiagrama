1. Встановлення (один раз)

  • Відкрийте bezeza.github.io/skiagrama у Chrome або Edge → «Встановити». Програма оновлюється сама, коли є інтернет; без інтернету теж працює.
  • «Налаштування» → ПІБ лікаря, реквізити закладу, бланк за замовчуванням.
  • «Налаштування» → папка даних, напр. D:\Skiagrama: архів, копія кожного протоколу й налаштування зберігаються туди самі.

2. Протокол за 5 кроків

  1. Угорі — пацієнт: ПІБ · вік (або дата народження) · № · дата · ЕЕД. Enter — до наступного поля.
  2. «Дослідження»: ОГК, ФГ, кістки, хребет, ОЧП, череп; проєкції.
  3. Норма всюди, потім у зміненій зоні — «Зміни» і кнопки.
  4. Висновок: прийміть підказку або виберіть свій; результат — норма / патологія / дообстеження. Текст можна правити прямо в протоколі.
  5. Готово (Ctrl+S) — в архів; Копіювати (Ctrl+Enter) — для h24; Друк (Ctrl+P); Зберегти як — PDF, Word.

3. Бланк і друк

  • Бланки: A офіційний · B сучасний · C компактний під штамп · D форма з полями. Перемикач — над аркушем протоколу.
  • Протокол друкується на пів аркуша A4; довгий — ущільнюється до 11 pt; якщо й так не вміщається — цілий аркуш з одного боку.
  • Програма підкаже, у якому бланку протокол вміститься, — кнопка «Застосувати».
  • Пачкою: «Архів» → «Вибрати ненадруковані» → «Друкувати вибрані». Розріжте по ✂.
  • Два дослідження одному пацієнту (ОГК + коліно) — два протоколи: після «Готово» → «+ Ще дослідження цьому пацієнту».
  • Критична знахідка — «Терміново»; в архіві натисніть «Повідомлено», коли повідомили лікаря.

4. Резервна копія

  • З папкою даних копії робляться самі (папки «копії» і «протоколи»).
  • Без папки: «Архів» → «Зберегти копію архіву» — щодня.
  • Свої фрази й кнопки на інший ПК — «Налаштування» → «Пакет фраз».
  • PDF і копії протоколів містять дані пацієнтів — не пересилайте їх в особисті чати.
