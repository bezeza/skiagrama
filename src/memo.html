1. Встановлення (один раз)

  • Відкрийте bezeza.github.io/skiagrama у Chrome або Edge → «Встановити». Без інтернету програма теж працює.
  • Або скопіюйте файл skiagrama.html на ПК і відкривайте його.
  • «Налаштування» → ПІБ лікаря, реквізити закладу, бланк за замовчуванням, папка даних (архів зберігається на диск сам).

2. Протокол за 5 кроків

  1. Вид дослідження вгорі: ОГК, ФГ, кістки, хребет, ОЧП, череп.
  2. Рядок пацієнта: ПІБ · вік · № · дата · ЕЕД (ЕЕД підставляється сама).
  3. Норма всюди, потім у зміненій зоні — «Зміни» і кнопки.
  4. Висновок: прийміть підказку або виберіть свій. Текст можна правити прямо в протоколі.
  5. Готово (Ctrl+S) — в архів; Копіювати (Ctrl+Enter) — для h24; Друк (Ctrl+P).

3. Бланк і друк

  • Бланки: A офіційний · B сучасний · C компактний під штамп · D форма з полями. Перемикач — біля протоколу.
  • Протокол друкується на пів аркуша A4; довгий — ущільнюється до 11 pt; якщо й так не вміщається — цілий аркуш з одного боку.
  • Програма підкаже, у якому бланку протокол вміститься, — кнопка «Застосувати».
  • Пачкою: «Архів» → «Вибрати ненадруковані» → «Друкувати вибрані». Розріжте по ✂.

4. Резервна копія

  • З папкою даних копії робляться самі (папка «копії»).
  • Без папки: «Архів» → «Зберегти копію архіву» — щодня.
  • Свої фрази й кнопки на інший ПК — «Налаштування» → «Пакет фраз».
