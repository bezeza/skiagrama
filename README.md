# Skiagrama

АРМ лікаря-рентгенолога: протокол рентгенологічного дослідження складається кнопками замість ручного набору.

**Відкрити:** https://bezeza.github.io/skiagrama/

## Що вміє
- ОГК, флюорографія, кістки й суглоби, хребет, ОЧП, череп і ППН.
- «Все в нормі», опис по зонах, вимірювання (КТІ, Кобб, кути стопи, кульшового суглоба тощо), підказки висновку.
- Архів протоколів, список «На контроль», шаблони лікаря.
- Друк пачкою: короткі протоколи по пів аркуша A4, довгі — з продовженням на звороті.
- Працює без інтернету, встановлюється як програма на ПК і телефон.

## Дані пацієнтів
Програма не надсилає жодних даних. Архів, шаблони й налаштування зберігаються лише в браузері пристрою, на якому відкрита програма. Резервну копію архіву зберігайте у файл (вкладка «Архів»).

## Встановлення
- **ПК (Chrome / Edge):** відкрити адресу → кнопка «Встановити» вгорі або значок установки в адресному рядку.
- **Android (Chrome):** меню ⋮ → «Додати на головний екран» / «Установити застосунок».
- **iPhone (Safari):** «Поділитися» → «На екран „Додому“».

## Оновлення
Новий випуск: змінити `VERSION` у `sw.js` (і номер версії в `index.html`). Користувачі побачать «Доступна нова версія — Оновити зараз».
